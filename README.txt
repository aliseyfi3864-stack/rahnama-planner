# راهنما پلنر — نسخه وب‌اپ

## محتویات
- `index.html`: برنامه اصلی
- `manifest.json`: مشخصات نصب روی صفحه اصلی
- `sw.js`: ذخیره پوسته برنامه برای بازشدن آفلاین پس از بارگذاری اولیه
- `icon.svg`: آیکن برنامه

## انتشار با GitHub Pages
1. مخزن `rahnama-planner` را باز کن.
2. این چهار فایل را در ریشه مخزن بارگذاری کن؛ فایل `rahnama-planner.html` را با نام `index.html` قرار بده.
3. در Settings → Pages، بخش Build and deployment را روی Deploy from a branch بگذار.
4. شاخه `main` و پوشه `/(root)` را انتخاب و Save کن.
5. پس از پایان انتشار، آدرس Pages که GitHub نمایش می‌دهد را باز کن.

## نکته مهم
ذخیره وظایف در این نسخه روی همان مرورگر/دستگاه انجام می‌شود. این اطلاعات به‌طور خودکار بین دستگاه‌ها همگام نمی‌شوند. قبل از پاک‌کردن داده‌های مرورگر، از داخل برنامه خروجی پشتیبان بگیر.
